## Start here

The Conformal Emergent Reality Model (CERM) asks whether the clocks and rulers used to describe the universe can arise from its geometry. The five manuscripts below develop that idea, from its mathematical foundations to its applications in particle physics and cosmology.

1. **Unfreezing Time and Mass** — Start with this short overview for the central ideas and how the papers fit together. (DOI: 10.5281/zenodo.23741406) [Latest revision on Zenodo](https://doi.org/10.5281/zenodo.23741406)
2. **Unfreezing Time** — Read this for the geometric clock, the recovery of Einstein gravity and quantum evolution under stated conditions, and the mathematical derivations. (DOI: 10.5281/zenodo.22947669) [Latest revision on Zenodo](https://doi.org/10.5281/zenodo.22947669)
3. **Fading Mass** — Read this for the proposed Standard Model extension and how the framework treats changing particle mass scales. (DOI: 10.5281/zenodo.23740321) [Latest revision on Zenodo](https://doi.org/10.5281/zenodo.23740321)
4. **Adaptive Dark Matter** — Read this for the Omegon proposal, in which local curvature sets the mass of a dark matter candidate, and its applications to galaxies and galaxy clusters. (DOI: 10.5281/zenodo.24090840) [Latest revision on Zenodo](https://doi.org/10.5281/zenodo.24090840)
5. **A Paired Tidal Test of Ultralight Vector Dark Matter** — Read this for a general pulsar-timing test method for scalar–tensor dark matter theories that uses a coherent vector field to cancel unknown dark matter density and measure scalar–curvature mixing within CERM. (DOI: 10.5281/zenodo.24218678) [Latest revision on Zenodo](https://doi.org/10.5281/zenodo.24218678)
